# Steam Discord Bot v3

بوت Discord للبحث عن حسابات Steam مع داشبورد ويب لإدارة السيرفرات والتوكنات.

## المميزات

- 🎉 **Free plan تلقائي** — كل سيرفر يضيف البوت يحصل على يومين مجاناً
- 🔍 بحث ذكي عن حسابات Steam باستخدام Groq AI
- 📢 إعلان تلقائي مع **كل** رسالة فيها حساب Steam
- ⏰ نشر تلقائي مع مقاطع TikTok عبر `/here`
- 🔑 توكنات عامة (أي سيرفر يقدر يستخدم أي توكن)
- 🎛️ داشبورد ويب لإدارة كل السيرفرات
- ⚠️ نظام تحذيرات عند حذف الإعلانات (6 تحذيرات ثم إيقاف)

## الأوامر

| الأمر | الوصف |
|-------|-------|
| `/steam <لعبة>` | البحث عن حساب Steam |
| `/here <دقائق>` | نشر تلقائي مع مقطع TikTok |
| `/stophere` | إيقاف النشر التلقائي |
| `/active <token>` | تفعيل البوت باستخدام توكن |

## متغيرات البيئة (Railway)

| المتغير | الوصف | مطلوب |
|---------|-------|--------|
| `DISCORD_TOKEN` | توكن بوت Discord | ✅ |
| `GROQ_API_KEY` | مفتاح Groq API | ✅ |
| `BOT_OWNER_SERVER_INVITE` | رابط دعوة سيرفرك للإعلانات | ✅ |
| `DASHBOARD_USER` | اسم مستخدم الداشبورد | ✅ |
| `DASHBOARD_PASS` | كلمة مرور الداشبورد | ✅ |
| `SESSION_SECRET` | سر الجلسة (أي نص عشوائي) | ✅ |
| `BOT_OWNER_DISCORD_ID` | Discord ID لصاحب البوت | اختياري |

## التثبيت على Railway

1. ارفع هذا الريبو على GitHub
2. في Railway: **New Project** → **Deploy from GitHub repo**
3. أضف متغيرات البيئة المطلوبة
4. أضف **Volume** على المسار `/app/data` لحفظ قاعدة البيانات
5. في إعدادات الـ service → **Networking** → افعّل **Public Networking** (Generate Domain)
6. انتظر حتى يكتمل الـ deploy

## كيف تدخل الداشبورد

بعد الـ deploy على Railway:
1. اذهب لـ Service → **Settings** → **Networking** → انسخ الـ domain
2. افتح `https://YOUR-APP.railway.app/` في المتصفح
3. سجّل بيانات الدخول التي حددتها في `DASHBOARD_USER` و `DASHBOARD_PASS`

## نظام التوكنات العام

التوكنات الآن عامة — أي سيرفر يقدر يستخدم أي توكن:

```
صاحب البوت (الداشبورد) → ينشئ توكن عام
              ↓
يرسله للسيرفر المطلوب (زر Send في الداشبورد)
              ↓
الأونر يكتب /active TOKEN في سيرفره
              ↓
البوت مفعّل!
```

## نظام Free Tier

- 🎉 عند إضافة البوت: يومين مجاناً تلقائياً
- 📢 إعلان مع **كل** رسالة Steam (دائماً، ليس فقط Free Tier)
- ⚠️ حذف الإعلان = تحذير 1/6 ... 6/6 = إيقاف
- 🔄 صاحب البوت يقدر يمدد الفترة المجانية أو يصفّر التحذيرات من الداشبورد
